# 🌳 Skill Forge

Skill Forge is an interactive RPG-inspired skill tree that transforms
professional development into a visual progression system.

Rather than representing education, certifications, and technical skills as
a checklist, Skill Forge maps them as interconnected abilities that unlock
as prerequisites are completed.

## ✨ Why I Built It

Traditional learning plans made it difficult to see how individual courses,
certifications, and projects connected to larger career goals.

I built Skill Forge to experiment with a different approach: treating
professional development like character progression in a role-playing game.

The project also gives me a practical environment for developing skills in
data structures, dependency mapping, interface design, and front-end
development.

## ⚔️ Features

- Interactive RPG-style skill tree
- Branching skill paths and prerequisite relationships
- Multiple professional development categories
- Visual progression through completed and unlockable skills
- Skill descriptions and progression requirements
- Expandable structure for future certifications and projects
