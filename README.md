# 🌳 Skill Forge

## Overview

Skill Forge is an interactive visualization of professional growth, certifications, projects, and learning journeys inspired by RPG progression systems.

Instead of tracking learning through checklists, Skill Forge visualizes progress as a living skill forest that grows over time.

---

## Current Status

🚧 Early Prototype

---

## Goals

- Build an interactive career progression map
- Visualize certifications and projects
- Track educational milestones
- Explore data visualization techniques
- Serve as both a personal motivator and portfolio project
